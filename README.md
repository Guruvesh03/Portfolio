## 📂 Featured Projects

### 01. Sentimate (Final-Year Project)
- **Overview:** Early-warning system for student mental health using a multilingual conversational survey.
- **Key Feature:** Explainable risk evaluation combining an XGBoost classifier with SHAP value explanations, designed with human-in-the-loop counsellor review rather than automated decisions.
- **Stack:** Python, XGBoost, SHAP, FastAPI, React, Supabase
- **Repository:** [SentiMate-Ai](https://github.com/Guruvesh03/SentiMate-Ai)

### 02. SecureCase (Smart India Hackathon 2026)
- **Overview:** Tamper-evident platform for FIRs, evidence records, and court documents.
- **Key Feature:** Browser-based SHA-256 byte fingerprinting via the Web Crypto API, paired with a five-role permission matrix, audit trail, and version history.
- **Stack:** React, Vite, Tailwind CSS, Framer Motion, Web Crypto API, IndexedDB
- **Repository:** [SecureCase](https://github.com/Guruvesh03/SecureCase)

### 03. Scholar Mentor
- **Overview:** Alumni mentorship and career guidance network connecting students with alumni from their own institutions.
- **Key Feature:** Multi-tenant relational PostgreSQL schema with isolated institutional communities on a single codebase.
- **Stack:** React, JavaScript, Bootstrap, Supabase, PostgreSQL
- **Repository:** [Scholar-Mentor](https://github.com/Guruvesh03/Scholar-Mentor)

## 🛠️ Local Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Guruvesh03/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build locally:
   ```bash
   npm run preview
   ```
